# Dźwięki

Wszystkie dźwięki generowane są w Web Audio (szum i oscylatory) — bez plików audio. Każde źródło jest umieszczone w miejscu zdarzenia (panner HRTF), a słuchaczem jest kamera, więc głośność i kierunek zależą od jej położenia. Głośność i barwa zależą od prędkości lub siły uderzenia.

| Checkbox | Źródło |
|---|---|
| Tarcie kół | Poślizg kół i przytarcie obrzeży o szynę |
| Łańcuch | Uderzenia ogniw o siebie i o hak |
| Sprzęg Janneya | Uderzenia metalu o metal w sprzęgu kłowym |
| Styki szyn | Koło przejeżdżające przez szczelinę między szynami |
| Zderzaki | Zetknięcie talerzy i dobicie do końca skoku |
| Koło o podkład | Koło uderzające w drewniany podkład po wykolejeniu |

Dźwięki startują dopiero po zaznaczeniu checkboxa (przeglądarka wymaga interakcji użytkownika).
